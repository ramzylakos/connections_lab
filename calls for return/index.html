Calls for Return

The British Museum’s collection holds more than 8,000,000 objects, many of which were collected as a result of colonisation. Countries around the world have been requesting that the British Museum return these objects for decades, but the museum refuses virtually all requests due to a law they created in 1963 that only allows for return under very specific conditions. In spite of this law, calls for return are still made every year. This map highlights 6 artworks that the museum calls 'contested objects'.
